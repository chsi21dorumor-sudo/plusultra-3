# Plus Ultra 0.2.0 - Quirk Evolution

## Added
- Skill points: players gain 1 skill point whenever they level up.
- Quirk Evolution screen opened with `V`.
- Six linked talent nodes: Power, Efficiency, Cooldown, Range, Technique, Mastery.
- Talent effects: ability power, stamina cost, cooldown, range and mastery bonuses.
- Quirk fusion unlocked at level 5 for 3 skill points.
- Fusion passives for the six existing Quirks.
- New HUD information for skill points, fusion and the Evolution shortcut.
- Continuous Quirk aura particles for the six Quirks.
- Custom villain model with horns, raised collar and shoulder armor.

## Controls
- `Z` = Quirk Ability 1
- `X` = Quirk Ability 2
- `C` = Plus Ultra Ability
- `V` = Quirk Evolution

## Build
This is the NeoForge 1.21.1 source project. Run `gradlew build` on a machine with Java 21 and internet access so Gradle can obtain the configured NeoForge/Gradle dependencies.
